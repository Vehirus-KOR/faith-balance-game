# PICK:ONE

**PICK:ONE**은 두 가지 선택지 중 하나를 고르고, 그 이유를 서로 이야기하며 자연스럽게 대화를 이어가는 **모바일 웹 기반 밸런스 카드 게임**입니다.

가벼운 일상 질문부터 가치관과 신앙에 관한 질문까지 다양한 주제를 다루며, 모임·수련회·소그룹·친교 프로그램 등 여러 상황에서 활용할 수 있도록 제작했습니다.

> **Pick one. Share your story.**

---

## 🎯 프로젝트 목적

PICK:ONE은 단순히 두 가지 선택지 중 하나를 고르는 것에서 끝나지 않습니다.

**질문 → 선택 → 선택 이유 → 자유로운 대화**

의 과정을 통해 참여자들이 서로의 취향과 생각, 가치관을 자연스럽게 알아가는 것을 목표로 합니다.

질문의 주제와 깊이를 다양하게 구성하여 가벼운 분위기에서 대화를 시작하고, 자연스럽게 더 깊은 이야기까지 이어갈 수 있도록 설계했습니다.

---

## 🎮 게임 방법

1. 원하는 카테고리를 선택합니다.
2. 화면의 카드 덱을 터치합니다.
3. 카드 셔플 후 무작위 질문이 등장합니다.
4. 두 가지 선택지 중 하나를 선택합니다.
5. 자신의 선택 이유를 이야기합니다.
6. 다른 참여자들과 자유롭게 의견을 나눕니다.
7. `다음 카드`를 눌러 다음 질문을 진행합니다.

## ✨ 주요 기능

* 모바일 환경 대응
* 전체 / 일반 / 신앙 카테고리 선택
* 무작위 질문 카드 추첨
* ★ 1~5 난이도 시스템
* 직전 카드 연속 등장 방지
* 카드 셔플 및 플립 애니메이션
* 질문 및 선택지 등장 효과
* 셔플 / 플립 / 질문 공개 효과음

## 🛠️ Tech Stack

* **HTML5** — 웹페이지 및 게임 UI 구조
* **CSS3** — 모바일 UI 및 카드 애니메이션
* **JavaScript** — 카드 추첨, 필터링, 게임 로직 및 효과음 제어
* **GitHub Pages** — 정적 웹사이트 배포

별도의 서버나 데이터베이스 없이 실행되는 **정적 웹 애플리케이션**으로 제작했습니다.
