# 신앙 밸런스 게임! 🎴

**Faith Balance Game**은 일반적인 밸런스 게임 형식을 활용하여
청년들이 재미있게 서로의 생각을 나누고 자연스럽게 신앙적인 대화까지 이어갈 수 있도록 제작한 **모바일 웹 기반 밸런스 게임**입니다.

**RE:UNION Special Program**을 위해 처음 제작되었으며, 이후 청년부 모임·수련회·소그룹·친교 프로그램 등에서 지속적으로 활용할 수 있도록 확장 가능한 형태로 구성했습니다.

---

## 🎯 프로젝트 목적

단순히 두 가지 선택지 중 하나를 고르는 게임을 넘어,

**질문 → 선택 → 선택 이유 → 자유로운 토론**

의 과정을 통해 참여자들이 서로의 생각과 가치관을 자연스럽게 알아가는 것을 목표로 합니다.

특히 신앙 카테고리는 정답을 맞히는 퀴즈가 아니라, 각자의 신앙생활과 생각을 부담 없이 나눌 수 있도록 구성했습니다.

---

## 🎮 게임 방법

1. 원하는 카테고리를 선택합니다.
2. 화면의 카드 덱을 터치합니다.
3. 카드 셔플 애니메이션 후 무작위 질문이 등장합니다.
4. 두 가지 선택지 중 하나를 선택합니다.
5. 자신의 선택 이유를 이야기합니다.
6. 다른 참여자들과 자유롭게 의견을 나눕니다.
7. `다음 카드`를 눌러 다음 사람에게 진행합니다.

---

## 🃏 카드 구성

현재 총 **50장의 질문 카드**가 포함되어 있습니다.

| 카테고리   |   카드 수 |
| ------ | -----: |
| 일반     |     25 |
| 신앙     |     25 |
| **전체** | **50** |

각 카테고리는 난이도에 따라 5단계로 구성됩니다.

| 난이도   | 특징                  |
| ----- | ------------------- |
| ★☆☆☆☆ | 가볍게 시작할 수 있는 질문     |
| ★★☆☆☆ | 취향과 성향이 드러나는 질문     |
| ★★★☆☆ | 가치관을 생각하게 하는 질문     |
| ★★★★☆ | 관계와 삶, 신앙에 대한 깊은 질문 |
| ★★★★★ | 깊은 대화가 필요한 DEEP 질문  |

각 난이도별로 일반 5장, 신앙 5장이 포함되어 있습니다.

## 🌱 Background

본 프로젝트는 **제1회 RE:UNION**의 특별 프로그램으로 기획되었습니다.

주바라기 캠프 이후 다시 모인 청년들이 함께 교제하며, 일반적인 대화에서 자연스럽게 신앙적인 이야기까지 이어갈 수 있는 콘텐츠를 만들기 위해 제작했습니다.

> “새벽 이슬 같은 주의 청년들이 주께 나오는도다.”
> 시편 110:3
